# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub: **Security → Report a vulnerability** on this
repository. Include steps to reproduce and the affected version. You can expect an
acknowledgement within a few business days.

## Supported versions

Only the latest release receives security fixes.

## Scope notes

This repository is a template. If you find a weakness in the CI/CD configuration (for
example an over-broad token permission or an injectable workflow step), that is in scope
and appreciated.
